# ClipPass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate Tollbooth to ClipPass: the agent reads a reel script and mood, licenses 1 music track, 3 b-roll clips and 2 SFX from a mock stock catalog, and pays each artist's own Testnet account per use through Noir, with the 2 XLM exclusive track refused by the card.

**Architecture:** Same monorepo and rails. `packages/shared` gains the asset catalog (`ASSETS`, `ARTISTS`, `MOODS`). The merchant route becomes `GET /api/assets/:id`, quoting each asset's price payable to its artist's address; the verifier checks the payment went to the quote's payee. `packages/agent` plans 7 slots, picks per slot by tag overlap then price, and records `License`s. Artists claim through one payout loop shared by the server, `npm run claim` and the demo.

**Tech Stack:** Node 24.22.1, TypeScript via `tsx`, Express 5, Vitest + supertest, Vite + React 18, `@noirx402/agent-sdk@0.3.0`, `@stellar/stellar-sdk@^16`, `@carts1024/velo-sdk@0.1.0-alpha.4` (all unchanged).

**Spec:** `docs/superpowers/specs/2026-11-06-clippass-design.md`

## Global Constraints

- Every constraint in `docs/superpowers/plans/2026-11-06-tollbooth.md` "Global Constraints" still holds (Noir only through the SDK, no contract overrides, Testnet only, bigint stroops, stroop strings over JSON, secrets only in `.env`, no human click triggers `authorizePayment`, README Noir writes link to real `file:line`).
- Packages are `@clippass/shared`, `@clippass/agent`, `@clippass/server`, `@clippass/web`; root package `clippass`.
- `DEVICE_UID` default stays `TOLLBOOTH-DEMO-0001`.
- `POLICY_MAX` 10_000_000n, `JOB_FEE` '1.00', `MIN_JOB_BUDGET` 20_000_000n, `MAX_JOB_BUDGET` 50_000_000n, `QUOTE_TTL_MS` 120_000: unchanged.
- Artist env keys: `ARTIST_LOWTIDE_SECRET`, `ARTIST_LANTERN_SECRET`, `ARTIST_KESTREL_SECRET`, `ARTIST_FERN_SECRET`. `MERCHANT_SECRET` is removed.
- Preview and download links use only the `clippass.example` domain.
- Demo reel: script `Rain at a night market in Manila, street food sizzle, crowd chatter`, mood `chill`, budget 2.5 XLM.
- Any command that sends Testnet transactions (`npm run setup`, `npm run demo`, `npm run claim`, a dev-route job) needs the user's go-ahead first.
- **Green checkpoints:** Tasks 2–5 change the agent↔merchant HTTP contract in steps. Within Tasks 2–4, only the test files each task names must pass; `apps/server/src/runner.test.ts` is expected to fail from Task 3 until Task 5. From the end of Task 5, `npm test` is fully green; from the end of Task 6, `npx tsc -p tsconfig.json --noEmit` is too; from the end of Task 7, `npx tsc -p apps/web/tsconfig.json --noEmit` is too. Each stays green after every later task.

## Review Focus

1. **Script with no tag words** (`hello world`): every slot is still filled (music by mood, other lanes cheapest unused), with `no tag match` in the reason. Test: Task 5 `script with no tag words still fills every slot`.
2. **Case, punctuation and plurals** (`RAIN!!! Night-markets… street-food`): matches `rain`, `night`, `market`, `street`, `food`. Test: Task 5 `matching ignores case, punctuation and suffixes`.
3. **Mood posted outside the dropdown** (`Chill`, `sad`, missing) or a script that is whitespace-only or 501 characters: 400 and no Velo session; exactly 500 characters is accepted. Test: Task 4 `rejects bad script or mood`.
4. **Planner gives every slot the same tag** (Ollama returns `market` for all three b-roll slots): three distinct b-roll assets, never a duplicate license. Test: Task 5 `same tag on every slot still licenses distinct assets`.
5. **Web lane prices or moods drift from the shared catalog** after someone edits `ASSETS`: a failing test, not a silently wrong chart. Test: Task 7 `web mirror matches the shared catalog`.

const open = ranked.filter((a) => !tried.has(a.id))
if (!open.length) return null
const [best, next] = open
let why: string
if (tried.has(ranked[0].id)) why = `${ranked[0].title} already used in this reel; next best ${best.title}`
